Description [src]

Iterates the cursor asyncronously to the next result.

If the cursor was not started, it will point to the first result after this operation completes.

In the period between this call and the corresponding tracker_sparql_cursor_next_finish() call, the other cursor methods should not be used, nor their results trusted. The cursor should only be iterated once at a time.
